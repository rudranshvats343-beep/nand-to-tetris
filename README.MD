NAND to Tetris – Rudransh Vats

About the Project

This repository contains my implementation of the NAND to Tetris course, focusing on building a computer system from basic logic gates.

Projects

Project 1 – Boolean Logic

* AND Gate
* OR Gate
* NOT Gate
* XOR Gate
* MUX
* DMUX

Project 2 – Boolean Arithmetic

* Half Adder
* Full Adder
* Add16
* ALU

Project 3 – Sequential Logic

* Memory components
* Registers
* RAM implementation

Technologies Used

* Hardware Description Language (HDL)
* Digital Logic Design
* VS Code
* Git and GitHub
